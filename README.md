# Office Placard: Shrine of Reheating

A one-line museum placard for the office microwave, written as if it were an
ancient artifact: a shrine where offerings of noodles were warmed and
abandoned, its door still beeping for the forgotten. `main.ts` reads
`entry.txt`, validates it (one line, 1–180 characters), and writes it
byte-identically to `$MAKEFUN_OUTPUT_DIR/entry.txt`, verifying the round trip.
